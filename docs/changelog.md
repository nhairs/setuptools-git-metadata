# Changelog

## [0.1.0] - UNRELEASED

### Added

- Record the declared package version, Git provenance, and build timestamps in source distributions and wheels.
- Provide a command to generate a customizable runtime loader for the embedded metadata.
- Preserve source provenance when building a wheel from a source distribution without Git.
- Add a release workflow that runs the test suite and publishes the source distribution and wheel to PyPI through Trusted Publishing.
